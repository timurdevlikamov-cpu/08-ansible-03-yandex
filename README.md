# ClickHouse + Vector + LightHouse

Данный Ansible-проект предназначен для автоматизированного развертывания стека инструментов для сбора и визуализации логов. Стек включает в себя базу данных ClickHouse, агент сбора данных Vector и веб-интерфейс LightHouse.

## 📋 Обзор архитектуры
Проект разворачивает три независимых компонента на разных хостах:
1. **ClickHouse Node**: СУБД ClickHouse (_установка из .deb пакетов_).
2. **Vector Node**: Агент для обработки и передачи данных (_установка из архива_).
3. **LightHouse Node**: Веб-интерфейс для работы с ClickHouse

## 🚀 Быстрый старт
### Требования
* Установленный Ansible на управляющей машине.
* Доступ по SSH к целевым узлам (Yandex Cloud).
* Наличие приватного SSH-ключа для аутентификации.

### Запуск
Для запуска всего playbook целиком используйте команду:
   ```bash
   ansible-playbook -i inventory/prod.yml site.yml --diff```
