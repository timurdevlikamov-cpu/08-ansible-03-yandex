# ClickHouse + Vector + LightHouse

Данный Ansible-проект предназначен для автоматизированного развертывания стека инструментов для сбора и визуализации логов. Стек включает в себя базу данных ClickHouse, агент сбора данных Vector и веб-интерфейс LightHouse.

## 📋 Обзор архитектуры
Проект разворачивает три независимых компонента на разных хостах:
1. **ClickHouse Node**: СУБД ClickHouse (_установка из .deb пакетов_).
2. **Vector Node**: Агент для обработки и передачи данных (_установка из архива_).
3. **LightHouse Node**: Веб-интерфейс для работы с ClickHouse

## 🚀 Быстрый старт
### Требования
* Установленный Ansible на управляющей машине.
* Доступ по SSH к целевым узлам (Yandex Cloud).
* Наличие приватного SSH-ключа для аутентификации.

### Запуск
Для запуска всего playbook целиком используйте команду:
```bash
   ansible-playbook -i inventory/prod.yml site.yml --check --diff
```

## 🛠 Описание Playbooks
### 1. Install Clickhouse
Цель: Установка сервера и клиента ClickHouse.
#### Задачи:
* Проверка наличия файлов и версии.
* Скачивание необходимых .deb пакетов (common-static, server, client).
* Установка пакетов через apt.
* Создание базы данных logs.
#### Handlers:
* Start clickhouse service: перезапуск сервиса при обновлении пакетов.

### 2. Install and Configure Vector
Цель: Развертывание агента Vector.
#### Задачи:
* Создание директорий для установки и конфигурации.
* Распаковка архива Vector.
* Деплой конфигурационного файла vector.yaml через шаблон (Jinja2).
* Проверка наличия исполняемого файла.
#### Handlers:
* Restart vector: перезапуск процесса при изменении конфигурации.

### 3. Install and Configure LightHouse
Цель: Развертывание GUI-интерфейса для ClickHouse.
#### Задачи:
Установка веб-сервера nginx и утилиты unzip.
Скачивание и распаковка репозитория LightHouse.
Перенос статических файлов в директорию веб-сервера.
Настройка конфигурации Nginx для обслуживания сайта.
Активация сайта (создание симлинка) и удаление дефолтного конфига Nginx.
#### Handlers:
* Restart Nginx: перезапуск веб-сервера при изменении настроек.

## ⚙️ Параметры и переменные
Проект использует переменные, определенные в group_vars/. Основные параметры:
| Переменная | Описание | Пример значения |
| :--- | :--- | :--- |
| `clickhouse_version` | Версия ClickHouse для установки | 22.3.3.44 |
| `vector_archive_url` | Прямая ссылка на скачивание архива Vector | `https://.../vector.tar.gz` |
| `vector_install_dir` | Путь, куда будет распакован Vector | `/root/vector/...` |
| `vector_config_path` | Путь к файлу конфигурации `.yaml` | `/root/vector/.../vector.yaml` |
| `lighthouse_archive_url` | URL репозитория LightHouse | `https://github.com/...` |
